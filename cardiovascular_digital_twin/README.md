# Cardiovascular System — Digital Twin

A lumped-parameter digital twin of the human cardiovascular system that
simulates and explains blood pressure, cardiac output, and ventricular
function across six physiological scenarios.

## Overview

The digital twin models the cardiovascular system as two coupled components:

| Component | Model | Key parameters |
|-----------|-------|---------------|
| **Heart** | Pulsatile pump with half-sine ejection profile | Heart rate (HR), stroke volume (SV), ejection fraction (EF) |
| **Vasculature** | Two-element Windkessel (resistance ‖ compliance) | Peripheral resistance R, arterial compliance C, venous pressure P_v |

### Governing equation

The arterial blood pressure *P* evolves according to the Windkessel ODE:

```
C · dP/dt = Q_heart(t) − (P − P_venous) / R
```

where `Q_heart(t)` is the periodic aortic flow waveform generated by the heart
model and the ODE is solved numerically with `scipy.integrate.odeint`.

## Physiological scenarios

| Scenario | Description | HR (bpm) | SV (mL) |
|----------|-------------|----------|---------|
| `normal` | Healthy adult at rest | 75 | 70 |
| `exercise` | Moderate aerobic exercise | 130 | 110 |
| `hypertension` | Stage-2 hypertension | 80 | 70 |
| `heart_failure` | Systolic heart failure (reduced EF) | 95 | 35 |
| `bradycardia` | Sinus bradycardia (slow heart rate) | 45 | 90 |
| `tachycardia` | Sinus tachycardia (fast heart rate) | 150 | 55 |

## Quick start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the full simulation (all scenarios, saves plots to outputs/)
python main.py

# 3. Run the test suite
python -m pytest tests/ -v
```

### Use the API directly

```python
from cardiovascular_digital_twin import CardiovascularSystem, Simulator
from cardiovascular_digital_twin import plot_simulation, plot_pv_loop

# Simulate the normal scenario
system = CardiovascularSystem.from_scenario("normal")
result = Simulator(system).run(n_cycles=15)

print(result.summary())
# {
#   'systolic_pressure_mmHg': 100.6,
#   'diastolic_pressure_mmHg': 76.7,
#   'pulse_pressure_mmHg': 23.9,
#   'mean_arterial_pressure_mmHg': 88.2,
#   'cardiac_output_L_per_min': 5.25,
#   'heart_rate_bpm': 75.0,
#   'stroke_volume_mL': 70.0,
#   'ejection_fraction': 0.583
# }

# Save a time-series plot
plot_simulation(result, save_path="normal_timeseries.png")

# Save a pressure–volume loop
plot_pv_loop(system, save_path="normal_pv_loop.png")
```

### Create a custom scenario

```python
from cardiovascular_digital_twin.models import Heart, Vasculature, CardiovascularSystem
from cardiovascular_digital_twin.simulation import Simulator

heart = Heart(heart_rate=55, stroke_volume=80)
vasculature = Vasculature(resistance=1.1, compliance=1.8)
system = CardiovascularSystem(heart=heart, vasculature=vasculature)

result = Simulator(system).run()
print(result.summary())
```

## Key physiological concepts illustrated

* **Pulse pressure** — determined primarily by stroke volume and arterial
  compliance (`PP ≈ SV / C`).  Reduced compliance (stiff arteries) widens
  the pulse pressure even at normal stroke volume (see *hypertension*).

* **Mean arterial pressure (MAP)** — approximately equals `CO × TPR`
  (cardiac output × total peripheral resistance).  Elevated resistance or
  high cardiac output both raise MAP.

* **Diastolic run-off** — characterised by the RC time constant (τ = R × C).
  Pressure decays exponentially during diastole at rate `1/τ`.

* **Ejection fraction (EF)** — the fraction of end-diastolic volume ejected
  per beat (`EF = SV / EDV`).  Normal EF ≥ 55 %; the *heart_failure* scenario
  demonstrates severely reduced EF (≈ 19 %).

* **Frank–Starling mechanism** — increased venous return (exercise, higher
  venous pressure) stretches the ventricle, raising EDV and thereby SV.

* **Pressure–Volume loop** — the four-phase cycle (isovolumetric contraction →
  ejection → isovolumetric relaxation → filling) visualised in the PV loop
  captures the mechanical work done by the heart per beat.
